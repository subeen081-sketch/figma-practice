# 의정부시청 「행사·축제」 서비스 UI/UX 개선

> 의정부시청 대표홈페이지의 행사·축제 화면을 손본 반응형 웹 리뉴얼입니다. 포스터 카드에서 일시·장소를 바로 보고, 목록·달력·상세를 거쳐 전화 문의까지 끊기지 않고 이어지도록 고쳤습니다.

## 3. 사용 기술

- **React 19, Vite**: 버튼·카드·달력을 컴포넌트로 나눠 모바일과 데스크탑 화면에서 같이 쓰려고 골랐고, Vite는 빌드가 빨라 고친 내용을 바로 확인할 수 있어서 썼습니다.
- **React Router**: 메인, 달력, 그리드, 상세 4개 화면 이동
- **GitHub Pages + GitHub Actions**: `main`에 push하면 자동으로 빌드하고 무료로 배포
- **Figma**: 개선 디자인 (KRDS 기준 디자인 토큰과 컴포넌트)
- **Claude**: 바이브코딩 (화면 구현)

## 4. 주요 기능

- **포스터 카드에 핵심 정보 표시**: 카드 하단에 일시·장소를 넣고, 진행 상태(접수중/진행중/마감)는 색과 글자를 함께 쓴 배지로 표시해서 카드를 눌러 보지 않아도 행사를 비교할 수 있게 했습니다.
- **그리드·달력·상세로 이어지는 탐색 흐름**: 그리드 보기에서는 포스터 카드가 제대로 나오고, 데스크탑 달력 화면에서는 목록을 스크롤해도 달력이 따라옵니다. 상세 화면 맨 위에는 포스터와 일시·장소·문의처를 배치했습니다.
- **모바일·데스크탑 반응형**: 1440px을 기준으로 모바일용과 데스크탑용 화면을 따로 보여 주고, 모바일은 KRDS의 360px 기준과 44px 이상 터치 영역을 지켰습니다.
- **자주 쓰는 메뉴 바로가기**: 모바일 하단 바로가기 바, 주요 서비스·시청 안내 항목의 호버 아이콘, 3열×2줄 푸터 메뉴를 넣었습니다.
- **접근성**: 아이콘만 있는 버튼에는 `aria-label`로 이름을 붙였고, 배너 일시정지 같은 토글 버튼에는 `aria-pressed`로 켜짐·꺼짐 상태를 알려 줍니다. 현재 쪽 번호에는 `aria-current`를 넣었고, 장식용 아이콘은 `alt=""`로 처리해 화면낭독기가 읽지 않게 했습니다 (KWCAG 2.2 기준).

## 5. 트러블슈팅

### 이슈 1: 배포한 사이트에서 하위 페이지를 새로고침하면 404가 나옴

- **문제**: `/figma-practice/calendar` 같은 하위 주소에서 새로고침하거나 주소로 바로 들어가면 GitHub Pages 404 화면이 나왔습니다.
- **원인**: GitHub Pages는 정적 파일 서버라서 `/calendar` 경로에 맞는 파일을 찾지 못했습니다. 화면 이동은 React Router가 브라우저 안에서만 처리합니다.
- **해결**: 배포 워크플로에서 빌드한 뒤 `index.html`을 `404.html`로 복사했습니다. 이제 어떤 경로로 들어와도 앱이 먼저 뜨고, 라우터가 맞는 화면을 보여 줍니다. 그리고 `vite.config.js`의 `base`(`/figma-practice/`)를 라우터의 `basename`에도 연결해서 저장소 이름이 붙은 경로가 맞게 동작하도록 했습니다.

### 이슈 2: 데스크탑 달력이 스크롤을 따라오지 않고, 따라오게 하니 목록 제목을 가림

- **문제**: 행사 목록을 내리면 오른쪽 달력이 화면 밖으로 사라졌습니다. 달력을 고정했더니 이번에는 긴 행사 제목 위를 덮었습니다.
- **원인**: 달력이 `position: absolute`로 한 위치에만 놓여 있었고, 목록 쪽에는 달력 폭만큼의 여백이 없었습니다.
- **해결**: 목록 오른쪽 끝까지 이어지는 세로 '레일'을 만들고, 그 안에서 달력을 `position: sticky`(화면 위 24px)로 붙였습니다. 이렇게 하면 달력이 목록 끝에서 멈춥니다. 또 목록에 달력 폭(322px)과 24px만큼 오른쪽 여백을 줘서 제목을 가리지 않게 했습니다.
