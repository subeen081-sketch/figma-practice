# CLAUDE.md

의정부시청 대표홈페이지 「행사·축제」 서비스의 UI/UX 개선 프로젝트 안내 문서입니다.
요구사항 원문은 `docs/PRD.md.md`입니다. 이 문서는 요약본이므로, 세부 내용은 원문을 확인합니다.

## 사용자

### 만드는 사람
- 코딩 초보자가 만드는 서비스입니다.
- 답변과 설명은 한국어로, 전문 용어는 쉬운 말로 풀어서 작성합니다.
- 코드를 바꾼 뒤에는 무엇을 왜 바꿨는지, 어떻게 확인하는지 알려 줍니다.
- 작업은 한 번에 하나씩 작은 단위로 진행합니다.

### 질문 규칙
- 모르거나 애매한 부분은 추측해서 구현하지 말고 먼저 질문합니다.
- PRD에 "추가 확인 필요" 또는 "다음 단계에서 확정 예정"으로 표시된 내용도 질문합니다.
- 질문할 때는 선택지와 각 선택의 차이를 쉽게 설명하고, 추천안이 있으면 함께 알려 줍니다.

### 서비스 이용자
- **일반 시민:** 포스터 카드로 여러 행사를 빠르게 비교하고, 상세 확인 후 바로 문의·공유하려는 사람입니다.
- **시각장애인 시민:** 스크린 리더와 키보드만으로 도움 없이 모든 행사 정보를 탐색하려는 사람입니다.

## 기술스택(변경금지)

| 구분 | 기술 |
|---|---|
| UI | React 19 |
| 빌드 도구 | Vite 8 |
| 언어 | JavaScript (`.jsx`) |
| 스타일 | 기본 CSS |
| 화면 이동 | react-router |
| 린트 | oxlint |

- 위 기술을 다른 기술로 바꾸지 않습니다. TypeScript, Tailwind, CSS-in-JS 등도 도입하지 않습니다.
- UI 라이브러리를 포함해 새 패키지가 필요하면 설치 전에 이유를 설명하고 허락을 받습니다.

### 명령어
```
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
npm run lint     # 코드 규칙 검사
npm run preview  # 빌드 결과 미리보기
```

## 디자인 규칙

### 디자인 구현 방식
- 디자인은 추후 Figma MCP로 시안을 읽어 구현합니다.
- Figma 링크를 받기 전에는 색상, 크기, 글꼴을 임의로 정하지 않습니다.
- 시안과 PRD가 다르면 임의로 고르지 말고 질문합니다.
- 반응형 상세 디자인은 구현 단계에서 사이즈별 Figma 링크로 전달받습니다.

### 반응형
- 모바일 우선으로 작성합니다. 기본 스타일은 모바일 기준이고, 큰 화면은 `min-width` 미디어쿼리로 확장합니다.

| 구분 | 범위 | 비고 |
|---|---|---|
| 모바일 | 360px ~ 1279px | 기본 스타일. 360px 폭으로 가운데 표시 |
| 데스크탑 | 1280px ~ | 데스크탑 레이아웃. 시안은 1440px, 1280~1439px은 같은 본문 폭으로 표시 |

- 360px 미만 화면에서도 가로 스크롤 없이 콘텐츠가 깨지지 않아야 합니다.
- 데스크탑 콘텐츠 영역은 `max-width: 80rem`으로 가운데 정렬합니다.
- 배경색·배경 이미지 등 전체 폭 요소는 화면 끝까지 채우고, 내부 콘텐츠만 최대 너비를 따릅니다.

### 단위
- 레이아웃은 `%`, `rem`으로 구성하고 고정 `px` 너비는 지양합니다.
- `em`은 사용하지 않습니다.
- 루트 글자 크기는 브라우저 기본값(1rem = 16px)을 유지하고, `html`에 고정 `px` 글자 크기를 지정하지 않습니다.
- 분기점(미디어쿼리)과 테두리 두께(1px 등)는 `px`을 사용해도 됩니다.

### 요소별 처리
- **주메뉴(GNB):** 모바일·태블릿은 전체메뉴 버튼, 데스크탑은 펼친 메뉴로 표시합니다. 세부 형태는 Figma를 따릅니다.
- **표:** 좁은 화면에서는 표 영역만 가로 스크롤되게 하고, 페이지 전체가 가로로 넘치지 않게 합니다.
- **이미지·미디어:** `max-width: 100%`를 적용하고 비율을 유지합니다.

### 접근성
- KWCAG 2.2와 KRDS 기준을 준수합니다.
- 뷰포트 메타 태그에서 사용자 확대를 막지 않습니다. `user-scalable=no`, `maximum-scale=1`은 사용하지 않습니다.
- 화면을 200%까지 확대해도 내용이 잘리거나 겹치지 않아야 합니다.
- 버튼·링크 등 터치 대상은 최소 2.75rem(44px) × 2.75rem을 확보합니다.
- 아이콘만 단독으로 쓰지 않고 레이블이나 툴팁을 함께 제공합니다.
- 포스터에는 대체 텍스트(`alt`)를 제공합니다.
- 키보드 초점 순서를 논리적으로 유지하고, 정렬·쪽 변경 후에도 초점을 보존합니다.
- 상태 배지는 색상만으로 구분하지 않고 텍스트를 함께 표시합니다.

### 문구
- 대표 명칭은 "행사·축제"로 통일합니다. "한눈에 달력" 등 다른 명칭은 화면에 쓰지 않습니다.
- PRD에 명시된 문구는 "그리드 보기", "리스트 보기", "목록으로", "길찾기", "전화 걸기", "총 00건"입니다.

## 서비스 구조

### 화면
```
행사·축제
├─ 목록: 그리드 보기(포스터 카드) ↔ 리스트 보기
├─ 캘린더: 월별 달력과 이번주 이벤트
└─ 상세: 포스터와 핵심 정보, 행동 버튼, 이전/다음 행사
```

### 기능 요구사항
우선순위가 높은 항목부터 구현합니다. 기능 ID는 PRD 4장을 따릅니다.

| 우선순위 | ID | 내용 |
|---|---|---|
| P1 | FR-01, 02 | 그리드 ↔ 리스트 전환 정상 동작, 선택한 보기 방식 유지 |
| P1 | FR-03 | 전환 버튼에 `aria-label`, `aria-pressed`, 호버·초점 시 레이블/툴팁 제공 |
| P1 | FR-04 | GNB, LNB, 페이지 타이틀, 서브 탭, 상세 제목을 "행사·축제"로 통일 |
| P1 | FR-14 | 보기 전환 아이콘을 KRDS 시스템 아이콘 표준 형태로 교체 |
| P2 | FR-09 | "오늘 이후/임박순" 기본 정렬, 기간·장소 필터, 종료된 행사는 뒤로 배치 |
| P2 | FR-13 | [목록으로], [이전/다음 행사], 복귀 시 검색 조건·쪽 번호·보기 방식 유지 |
| P3 | FR-05 | 카드 하단에 기간(일시)·장소를 한 줄로 표시 |
| P3 | FR-06 | 포스터가 없어도 리스트에 카테고리 태그와 상태 배지 표시 |
| P3 | FR-07 | 상태 배지를 색상+텍스트로 표시 |
| P3 | FR-08 | 목록 표의 제목 열 확보, 단어 단위 줄바꿈, 상단 "총 00건" 표시 |
| P4 | FR-10 | 상세 상단에 포스터와 일시·장소·문의처 배치, 모바일은 수직 배치 |
| P4 | FR-11 | 전화 `tel:` 링크, [길찾기] 버튼, 공유 아이콘 툴팁, X 로고 교체 |
| P4 | FR-12 | 모바일 상세 하단에 [전화 걸기]/[길찾기] 고정 |

### 폴더
```
docs/       # PRD와 이 문서
src/
├─ main.jsx   # 앱 시작점
├─ App.jsx    # 최상위 컴포넌트
├─ index.css  # 전역 스타일
├─ assets/
│  ├─ icons/    # 아이콘 PNG
│  └─ images/   # 아이콘이 아닌 이미지 (포스터 등)
├─ components/  # 컴포넌트와 같은 이름의 CSS를 종류별로 보관
│  ├─ icon/      # 아이콘
│  ├─ label/     # 상태·종류 라벨
│  ├─ button/    # 버튼
│  ├─ card/      # 카드와 카드 안의 이미지·설명
│  ├─ calendar/  # 캘린더
│  ├─ layout/    # 머리말·푸터 등 화면 공통
│  ├─ main/      # 메인 화면 전용
│  ├─ detail/    # 상세 정보
│  └─ form/      # 검색창·콤보박스
├─ data/      # Figma 내용으로 만든 임시 데이터
├─ fonts/     # Pretendard GOV 폰트 파일
├─ pages/     # 화면: 메인, 캘린더, 그리드, 상세
└─ styles/
   ├─ fonts.css   # Pretendard GOV 폰트 등록
   ├─ tokens.css  # Figma 디자인 토큰
   ├─ reset.css   # 브라우저 기본 스타일 초기화
   └─ base.css    # body, 제목, 링크 기본 스타일
index.html
```

### 확정된 결정
PRD나 시안과 다르더라도 아래 결정을 우선합니다.

| 항목 | 결정 |
|---|---|
| 데이터 | 실제 API가 없는 동안 Figma 내용으로 만든 임시 데이터 파일을 사용 |
| 화면 이동 | `react-router` 사용 |
| 캘린더 화면 | 시안대로 포함 |
| 상태 표기 | 진행전/진행중/진행종료 사용. 오늘이 시작일 전이면 진행전, 시작일~종료일이면 진행중, 종료일 후면 진행종료 |
| 결과 0건 | 안내 문구 표시 |
| 전화번호·주소 없음 | 해당 버튼 숨김 |
| 이미지 없음·로드 실패 | 시안의 빈 흰색 틀 표시 (별도 대체 이미지 없음) |
| 검색창 문구 | "Search" 대신 "검색어를 입력하세요" |
| 음성 검색 버튼 | 시안대로 유지. 동작은 아직 정해지지 않음 |
| 데스크탑 콤보박스 | 이벤트 종류 선택: 전체, 행사, 축제, 공연 |
| 첫·마지막 행사 | 없는 쪽의 이전/다음 버튼 숨김 |
| 모바일 카드 열 수 | 시안대로 2열 |
| 모바일 상세 고정 바 | PRD대로 [전화 걸기]/[길찾기] 고정 바 포함 |
| 터치 대상 크기 | 누르는 영역은 최소 44px, 눈에 보이는 크기는 시안을 따름 |
| 모바일 좌우 여백 | 전체 화면 16px로 통일 |
| 데스크탑 너비 | `80rem`을 바깥 한계로 두고, 안쪽 콘텐츠 폭은 시안을 따름 |
| 글꼴 | 시안대로 Pretendard GOV, Pretendard, Noto Sans KR 사용. 구현하며 필요하면 다시 판단 |
| 제목 단계 | `h1`은 `maincard/tit`, `h2`는 `card/tit-desktop`, `h3`~`h6`은 `body/tit` 스타일 사용 |
| 링크 모양 | 기본은 주변 글자색에 밑줄 없음, 마우스를 올리면 밑줄. 본문 안의 링크는 화면 구현 때 밑줄을 넣어 구분 |
| 브레이크포인트 | 1280px 하나. PRD의 768px은 태블릿 시안을 받으면 추가 |
| 데스크탑 사이드바 | 1280~1439px에서는 본문을 가려 숨기고, 1440px부터 표시 |
| 코드 이름 | 컴포넌트, 클래스, 파일, 속성 이름은 영어로 작성. 화면에 보이는 문구와 주석은 한국어 유지 |
| 목록 버튼 문구 | 시안대로 모바일은 "목록", 데스크탑은 "목록으로" |
| 겹화살표(≫) 버튼 | 스크린 리더용 이름은 "마지막 쪽" |
| 이전 쪽 버튼 | 시안이 없어 만들지 않음. 시안을 받으면 추가 |

## 안전규칙
- 파일이나 폴더를 삭제하거나 덮어쓰기 전에 대상을 확인하고 허락을 받습니다.
- `docs/PRD.md.md`는 요청이 있을 때만 수정합니다.
- 요청받지 않은 기능이나 리팩터링을 추가하지 않습니다.
- Git 커밋과 푸시는 요청이 있을 때만 합니다.
- Figma 파일 수정은 요청이 있을 때만 합니다.
- 비밀번호, API 키, 토큰을 코드에 넣지 않습니다.
- 실제 개인정보를 예시 데이터로 쓰지 않습니다.
- 코드를 바꾼 뒤 `npm run build`와 `npm run lint`를 실행하고, 결과를 그대로 알려 줍니다.
- 확인하지 못한 내용을 완료했다고 말하지 않습니다.
- 오류가 나면 원인을 쉽게 설명하고, 해결 방법을 제안합니다.
