# 홍보 모션 영상 아이디어

- 피그마: [공공사이트개선 / 모바일완성화면](https://www.figma.com/design/zTXzU0vK1FnehvHMx0a6uR/%EA%B3%B5%EA%B3%B5%EC%82%AC%EC%9D%B4%ED%8A%B8%EA%B0%9C%EC%84%A0?node-id=851-3564)
- 페이지: `모션` / 섹션: `모바일완성화면` (851:3564)
- 섹션 안 화면: `모바일-메인`, `모바일-캘린더`, `모바일-그리드`, `모바일-상세설명페이지`, `모바일-상세설명페이지(열림)` (모두 모바일, 360px 너비)
- 데스크탑 화면은 이 섹션에 없음 → 영상에 넣을지 **확인 필요**

## 1. 장면 구성

| 장면 | 사용할 화면 | 이유 |
|---|---|---|
| 1. 오프닝 | `모바일-메인` 상단 `헤더섹션` (851:3868) | 로고, "시민의 뜻으로, 새로운 의정부" 문구, 검색창, 인구·미세먼지 정보가 한 화면에 있어 첫인상으로 좋음 |
| 2. 소식과 서비스 | `모바일-메인` 중단 (주요서비스, 보도자료, 새소식, 행사/축제) | 서비스와 최신 소식이 이어져 있어 스크롤하며 "한곳에서 다 본다"는 메시지 전달 |
| 3. 행사 일정 확인 | `모바일-캘린더` (851:3565) | 달력, 이벤트 표시 점, 이번주 이벤트 카드가 함께 있어 일정 기능을 가장 잘 보여줌 |
| 4. 행사 찾기 | `모바일-그리드` (851:3655) | 검색창과 카드 10장(2열)이 있어 검색하고 둘러보는 흐름 표현 |
| 5. 상세 정보 확인 | `모바일-상세설명페이지` (851:3722) → `(열림)` (851:3789) | 닫힘·열림 화면이 둘 다 있어 상세설명이 펼쳐지는 동작으로 마무리 가능 |
| (참고) 엔딩 | **없음** | 로고·슬로건으로 끝나는 엔딩 화면이 파일에 없음 |

## 2. 따로 움직일 요소와 분리 여부

| 장면 | 따로 움직일 요소 | 분리 여부 | 비고 |
|---|---|---|---|
| 1 | 로고, 슬로건 텍스트, 검색창, 인구·미세먼지 정보, 시장 사진 | 불필요 | 이미 각각 다른 레이어 |
| 1 | 생애주기 메뉴 아이콘 5개 | 불필요 | 각각 인스턴스라 하나씩 등장 가능 |
| 1 | `모바일슬라이드` 배너 이미지 넘김 | **필요 (Detach)** | 인스턴스 안 `Frame 41`(너비 5488px)에 이미지 13장이 가로로 이어져 있음 |
| 2 | `보도자료 모바일` 가로 슬라이드 | **필요 (Detach)** | 슬라이드 7장이 인스턴스 안에 있어 위치를 옮길 수 없음 |
| 2 | `메인SNS배너슬라이드` | **필요 (Detach)** | 슬라이드 5장이 인스턴스 안에 있음 |
| 2 | 행사/축제 카드 4장 | 불필요 | 각각 인스턴스 |
| 3 | 이벤트 표시 점 | 불필요 | 각각 인스턴스 |
| 3 | 날짜 줄 밖에 떨어진 점 2개 (851:3616, 851:3617) | **필요 (위치 정리)** | 4~10일 줄 프레임(851:3597) 안으로 옮겨야 줄과 같이 움직임 |
| 3 | 노란색 "이번주" 강조 | **확인 필요** | 날짜 줄 프레임에는 배경이 없음. 날짜칸 컴포넌트 안에 있는 것으로 보이며, 따로 움직이려면 별도 레이어가 필요할 수 있음 |
| 3 | 이번주 이벤트 카드 3장 | 불필요 | 각각 인스턴스 |
| 4 | 검색창 글자 타이핑 효과 | **필요 (Detach)** | 텍스트가 인스턴스 안에 있고 현재 "Search" 영문 기본값. 실제 검색어는 **확인 필요** |
| 4 | 카드 10장 순차 등장 | 불필요 | 각각 인스턴스 |
| 4 | 카드 안 "진행전/축제" 라벨만 따로 움직이기 | 필요 (그렇게 할 때만) | 카드 전체를 움직이면 분리 불필요 |
| 5 | 상세설명 박스 펼침 | 불필요 | 두 화면 사이 전환으로 처리 |
| 5 | 두 화면 레이어 구조 맞추기 | **필요** | 닫힘 화면은 `상세정보`가 `Frame 23` 안에 있고, 열림 화면은 `Frame 25`에 따로 있음. 메인카드 y도 92/102로 달라 Smart Animate가 레이어를 잘못 짝지을 수 있음 |
| 엔딩 | 로고, 슬로건 | **없음** | 화면을 새로 만들어야 함 |

## 3. 작업 계획 (원본은 건드리지 않음)

`모바일완성화면` 섹션 오른쪽에 `모션용화면` 섹션을 새로 만들고, 화면 5개를 복제해 복사본만 수정한다.

### 3-1. 엔딩 화면 `모션-05-엔딩` (360×780)

| 요소 | 내용 |
|---|---|
| 배경 | 메인 상단 영역과 같은 그라데이션 (흰색 → 연한 파랑 #D7E9F9) |
| 로고 | `새로운의정부아이콘` 인스턴스 (240×51), 가운데 배치 |
| 슬로건 | "시민의 뜻으로," / "새로운 의정부" 두 줄. 메인과 같은 텍스트 스타일(Noto Sans KR Bold 20), 메인 텍스트에 연결된 색 변수 그대로 사용 |
| 하단 로고 | `의정부시 아이콘` 인스턴스 |
| 누리집 주소(URL) | **확인 필요** (정확한 주소를 받으면 추가) |

각 요소는 별도 레이어로 두어 순서대로 등장시킬 수 있게 한다.

### 3-2. 화면별 분리 작업

| 복사본 | 작업 |
|---|---|
| 메인 | `모바일슬라이드`, `보도자료 모바일`, `메인SNS배너슬라이드` 세 인스턴스 Detach |
| 캘린더 | 떨어진 점 2개를 4~10일 줄 프레임 안으로 옮기고 `Absolute position` 설정. "이번주" 강조는 위치 확인 후 필요하면 노란 사각형을 별도 레이어로 추가 |
| 그리드 | 첫 번째 검색창 인스턴스 Detach → 텍스트를 직접 수정 가능하게 |
| 상세 (닫힘) | `상세정보`를 `Frame 23` 밖으로 꺼내 새 프레임 `Frame 25`에 넣기, `Frame 23` y를 92 → 102, 메인카드 y를 0으로 맞추기, 레이어 이름·순서를 열림 화면과 동일하게 맞추기 |

## 4. 현재 막힌 점

- 계정의 모든 팀이 Starter 플랜 **View 좌석** → Figma MCP로 편집 불가 (`Can't call "createSection" in read-only mode`)
- 해결: 이 파일이 있는 팀에서 **Full(편집) 좌석**으로 변경하거나, 위 작업 계획대로 직접 작업
